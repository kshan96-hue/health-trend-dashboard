# health-trend-dashboard

건강기능식품 시장 트렌드 대시보드 (단일 HTML 파일, 외부 CDN 없음).

- 공개 페이지: https://kshan96-hue.github.io/health-trend-dashboard/
- 원본 파일: `index.html` (`건기식-트렌드-대시보드-2026-11-25.html`)
- 2026-11-25 1회차 브리핑 데이터 기준. 시장·규제·채널·검색·커머스 랭킹을 한 장에 정리.
- 확인하지 못한 항목은 '미확인'으로 표기, 해석이 들어간 부분은 '해석'·'추정'으로 구분.
- 매일 아침 브리핑 데이터로 `index.html`만 교체하면 같은 주소에서 갱신된 대시보드를 볼 수 있음.
